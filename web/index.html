Display for Tempest Weather Station

Elecrow CrowPanel Advance 10.1" (ESP32-P4) — version 1.0.0

First install (USB)

Chrome or Edge, USB cable, 5 V / 2 A supply (PC USB ports brown out this panel). Puts bootloader, app, and icon storage on the flash in one shot.

If the button is missing, this browser does not support Web Serial.

Later updates (OTA)

Once the panel is on Wi-Fi, do not re-flash the merged image. Upload only the app binary:

  • Browser: http://tempest.local:8080/ota
  • File: tempest_display.bin from the latest release (not merged-firmware.bin)
  • Script: curl -X POST --data-binary @tempest_display.bin http://tempest.local:8080/ota/update

OTA writes the unused 3 MB slot and reboots. A bad image rolls back automatically. It does not rewrite the SPIFFS icon partition.
